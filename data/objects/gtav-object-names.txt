# Curated object-spawner prop list for the menu's World > Spawn Object browser.
#
# One prop per line: `model<TAB>Label<TAB>Category`. The Category column drives the
# in-menu category filter (mirrors the vehicle-class filter). Lines beginning with
# '#' and blank lines are ignored.
#
# Every model here was verified to exist in this game version's prop dump
# (data/objects/menyoo-PropList.txt, the vendored Menyoo prop list). These are stock, reliably
# spawnable props -- map/LOD/proxy tiles are deliberately excluded. The runtime
# still validates each with IS_MODEL_* before CREATE_OBJECT, so an unknown name
# would degrade to "model not valid" rather than crash.
#
# Regenerate the C header after editing: `make object-registry`.
